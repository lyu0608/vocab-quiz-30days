## 1.0.0（2026-11-06）by Claude Code

第一版（macOS），由 Claude Code 開發。

- **官方社區玩法**：直接瀏覽 ai-passport.folotoy.cn 的玩法社區（搜尋、分類、排序），
  下載後核對 SHA-256 再寫入，寫入方式與官方網頁安裝相同（0x0 完整映像、不整片清除）。
- **開源專案**：GitHub 專案下載 → ESP-IDF 編譯 → 上傳，內建「客語朗讀練習」與 FoloToy 官方示範；
  可自行新增 GitHub 或本機專案、指定分支／標籤、查看提交紀錄並選舊版本。
  預設分段寫入（等同 idf.py flash，會一併寫入錄音等資料分區，保留 Wi-Fi 設定）。
- **韌體檔**：本機 .bin 或 GitHub Releases 的 .bin，自動判斷寫入位址並檢查是否為 ESP32-C3 韌體。
- **上傳紀錄**：記錄每次上傳的時間、內容、版本、裝置 MAC 與結果，可一鍵重新上傳。
- 可一鍵安裝 ESP-IDF v5.5.3。
- 安全：永遠不做 erase-flash；不是 ESP32-C3 的韌體、超出 8 MB、位址不對都會在寫入前擋下。
