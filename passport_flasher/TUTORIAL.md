# 使用教學

## 開始之前

這個工具用 USB-C 線把新的玩法或韌體寫進 FoloToy AI Passport。

你需要：

- 一台 Mac
- AI Passport（要有電、可以開機）
- 一條**可傳資料**的 USB-C 線（有些線只能充電，接上後會找不到裝置）

可以上傳三種內容，各有一個分頁：

- **官方社區玩法**：別人做好、放在官方社區的玩法，選了就能裝，最簡單
- **開源專案**：GitHub 上的原始碼（例如客語朗讀練習），工具會幫你下載、編譯再上傳
- **韌體檔**：已經有 `.bin` 檔，直接上傳

## ① 連接裝置

1. 用 USB-C 線把 AI Passport 接到 Mac，並把裝置開機
2. 視窗最上方的「序列埠」會自動出現 `/dev/cu.usbmodem…  ✅ AI Passport`
3. 想確認連線正常，可以按「**檢查裝置**」，下方會顯示 `✅ 已連線：ESP32-C3`

**找不到裝置時：**

- 確認裝置已開機
- 換一條可傳資料的線，或換 Mac 上另一個 USB 孔，盡量不要用集線器
- 按「重新整理」
- 關閉其他可能佔用裝置的程式：官方安裝網頁、序列埠監看工具、Arduino 等

## ② 安裝官方社區玩法

1. 切到「**官方社區玩法**」分頁
2. 用「搜尋」「分類」「排序」找玩法，★ 是官方玩法
3. 點一下清單裡的玩法，右邊會顯示介紹、使用方式和更新內容
4. 按「**⬆ 上傳到 AI Passport**」（或直接在清單上按兩下）
5. 工具會先下載韌體並核對檔案正確，再跳出確認視窗，按「確定」開始寫入
6. 進度條跑完會顯示「已寫入並校驗成功」，裝置自動重新開機

**注意：**社區玩法會覆蓋原本的玩法和配網（Wi-Fi）設定，裝完後依裝置畫面指示重新設定即可。

下載過的韌體會保留在電腦裡，再裝同一個版本時不必重新下載。

## ③ 上傳開源專案（例如客語朗讀練習）

開源專案需要先在電腦上編譯，第一次會花比較多時間。

1. 切到「**開源專案**」分頁
2. 左邊清單選專案，★ 客語朗讀練習排在第一個
3. 第一次使用要先準備 ESP-IDF（編譯工具），見下一章「安裝 ESP-IDF」
4. 按「**一鍵：下載 → 編譯 → 上傳**」
5. 等待下載和編譯（第一次約 5–15 分鐘，之後只要幾十秒），進度條會顯示編譯進度
6. 跳出確認視窗後按「確定」寫入

也可以分開按「① 下載／更新原始碼」「② 編譯」「③ 上傳」。

**寫入方式：**

- **分段寫入（建議）**：和 `idf.py flash` 一樣，會一起寫入錄音等資料，**保留 Wi-Fi 設定**
- **完整寫入 0x0**：和官方社區安裝一樣，會清除設定

**新增其他專案：**按「＋ GitHub」貼上網址（例如 `https://github.com/owner/repo`），或按「＋ 本機資料夾」選擇電腦上的專案。

## 安裝 ESP-IDF（只需一次）

ESP-IDF 是 Espressif 官方的編譯工具，編譯開源專案時需要。

**自動安裝：**

1. 先在「終端機」執行一次，安裝 Apple 開發者工具（已裝過可跳過）：

```
xcode-select --install
```

2. 建議先安裝 [Homebrew](https://brew.sh)，工具會用它自動安裝 cmake 和 ninja
3. 在「開源專案」分頁按「**安裝 v5.5.3**」，約需 10–30 分鐘、1–2 GB 空間
4. 完成後「ESP-IDF」欄位會顯示 `✓ ESP-IDF v5.5.3`

**已經裝過：**在「ESP-IDF」欄位按「選擇…」，選有 `export.sh` 的資料夾，例如 `~/esp/esp-idf-v5.5.3`。

## ④ 上傳韌體檔（免編譯）

1. 切到「**韌體檔**」分頁
2. 按「選擇檔案…」選 `.bin` 檔
3. 工具會自動判斷檔案種類，並顯示要寫入的位置：
   - **完整映像**（例如 `FoloToy-AI-Passport-full.bin`）→ 寫到 0x0
   - **只有應用程式** → 寫到 0x10000
4. 「寫入位址」保持「自動判斷」即可；只有韌體作者特別說明時才用「自訂位址」
5. 按「**⬆ 上傳到 AI Passport**」

**從 GitHub Releases 下載：**在「Repo」貼上專案網址，按「讀取 Releases」，選一個 `.bin`，再按「下載並選用」。

## ⑤ 上傳紀錄與重新上傳

「**上傳紀錄**」分頁會記錄每一次上傳：

- 時間、結果（成功／失敗／停止）
- 上傳了什麼、從哪裡來、版本
- 裝置 MAC（有多台 AI Passport 時，可以分辨是哪一台）

選一筆紀錄後按「**⬆ 重新上傳這一筆**」，可以把同一個版本再裝一次，例如把裝置換回之前的玩法。

## ⑥ 備份與還原

寫入新韌體會覆蓋裝置上原本的玩法和設定。先備份，想換回來時就能一鍵還原。

**寫入前備份（建議）：**
每次按上傳，確認視窗都會有「**寫入前先備份裝置目前的韌體**」，預設勾選。
勾選後會先把整片 8 MB Flash 讀到電腦（約 1–3 分鐘），備份成功才開始寫入；備份失敗就不寫入。

**隨時手動備份：**
切到「**備份**」分頁，按「**💾 立即備份**」。

**還原：**

1. 在「備份」分頁選一個備份（「內容」顯示 ✓ 可還原）
2. 按「**↺ 還原這個備份**」
3. 工具會先確認接的是不是當初那台裝置（比對 MAC），不同台會提醒你
4. 確認後寫回，裝置上的玩法和 Wi-Fi 等設定都會變回備份當時的樣子

**小提醒：**

- 每個備份約 8 MB，存在 `~/PassportFlasher/backups/`，用不到的可以按「刪除」
- 備份包含 Wi-Fi 密碼等設定，請不要隨便分享備份檔
- 「上傳紀錄」裡每一筆也會記下寫入前的備份檔在哪裡

## ⑦ 查看版本

- **本工具的版本**：右上角「版本紀錄」，或選單「說明 → 燒錄工具版本紀錄」
- **開源專案的版本**：「開源專案」分頁按「**版本歷史…**」，可以看每次提交和專案的更新說明
  - 想裝舊版：選一個版本，按「使用選取的版本」，再按「一鍵：下載 → 編譯 → 上傳」
  - 想回到最新版：按「回到最新版」（或把「分支／標籤」清空）

## 常見問題

**寫到一半停止或拔線了怎麼辦？**
裝置可能暫時無法開機，這是正常的。重新接上，再上傳一次就會恢復。

**出現「Failed to connect」或「打不開序列埠」？**
關閉其他使用裝置的程式（官方安裝網頁、序列埠監看工具等），拔插 USB-C 後再試。

**傳輸一半出錯、校驗失敗？**
把視窗上方的「速度」改成 115200，換一條線或 USB 孔再試。

**裝完後裝置畫面沒變？**
拔下 USB 線，重新開機。

**會不會把裝置弄壞？**
這個工具不會整片清除 Flash，寫入前也會檢查韌體是不是給 AI Passport（ESP32-C3）用的、大小和位置對不對。就算寫壞了，重新上傳正確的韌體就能恢復。

**檔案放在哪裡？**
下載的專案和韌體在 `~/PassportFlasher/`（選單「說明 → 打開下載資料夾」），設定和上傳紀錄在 `~/Library/Application Support/PassportFlasher/`。

**還有問題？**
按「複製紀錄」，把紀錄貼給協助你的人；也可以看官方教學網站。
